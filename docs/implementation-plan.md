# Implementation Plan

## Phase 1 — Core Decode & Settings (Day 1 AM)
- [ ] Xcode project, SwiftLint, ZXingObjC via SPM
- [ ] Settings store: `@AppStorage` keys for `validatorRegex`,
      `defaultBoxLayout`, `includeProvenanceColumn`, `retentionDays`,
      `maxStorageBytes`, `gapThresholdMultiplier`, `outlierSigmaThreshold`
      (all initialized to CEL-flavored defaults)
- [ ] `PayloadValidator` service (regex compile + match), reads from settings
- [ ] `BarcodeScanner` service (Vision + ZXing fallback)
- [ ] Bounding box coordinate conversion (Vision → UIKit top-left)
- [ ] `ScanPipeline` actor scaffold + `PipelineEvent` types
- [ ] TestBed CLI target (SwiftPM) — discovers bare images and bundle dirs
- [ ] Testbed runs against `TestImages/46__sparsed_missing.jpg`

## Phase 2 — Grid Inference & Quality (Day 1 PM)
- [ ] `BoxLayout` enum + per-scan override plumbing
- [ ] `GridInferencer.infer(codes:, layout: .auto)` — PCA, 1D gap clustering
- [ ] `GridInferencer.infer(codes:, layout: .fixed(rows, cols))` — centroid →
      ideal-position mapping
- [ ] `CellStatus` / `UnreadableReason` types; outliers map to (row=-1, col=-1)
- [ ] `ImageQualityAnalyzer`: variance-of-Laplacian (blur), luminance + clipping
- [ ] `ScanQualityReport` assembly inside the pipeline
- [ ] Unit tests: synthetic grids (3×4, 5×5, 1×N, N×1, rotated 45°,
      missing corners, sparse 9×9, codes outside fixed layout)

## Phase 3 — Annotation (Day 2 AM)
- [ ] `ImageAnnotator`: bounding boxes + payload labels
- [ ] Color matrix: green (decoded), orange (unreadable), blue (user-edited),
      yellow dashed (empty in fixed layout)
- [ ] Reason labels for unreadable cells (e.g. "rejected: AOO011", "blur")
- [ ] Grid lines + row/col edge labels
- [ ] CIContext GPU backing
- [ ] Performance: 100-code annotation < 2s on iPhone 12

## Phase 4 — CSV, Export, Persistence (Day 2 AM/PM)
- [ ] `CSVExporter`: row,col,code with `null` for missing/unreadable;
      optional `status` column gated by `includeProvenanceColumn`
- [ ] Copy to clipboard
- [ ] UIActivityViewController share sheet
- [ ] Save to Files (UIDocumentPickerViewController)
- [ ] SwiftData `StoredScan` model + `StorageManager` service
- [ ] Photo files written to `Application Support/Scans/<uuid>/`
- [ ] Auto-trim on launch + post-scan (photos only; record retained)
- [ ] `TestCaseExporter`: produces a bundle (input.jpg + detected.json +
      expected.csv + metadata.json) and hands a URL to share sheet

## Phase 5 — UI & Editing (Day 2 PM / Day 3 AM)
- [ ] `ScanView`: camera capture (custom shutter + torch) + Photos picker
- [ ] Per-scan layout override on `ScanView` (one-tap menu)
- [ ] `ResultView`: streamed rendering — grid first, annotated image second
- [ ] `GridView`: SwiftUI table; tap-to-highlight in annotated image
- [ ] Cell editor: edit decoded value, populate empty, fix `validatorRejected`
      with pre-filled highlighted misread chars
- [ ] `RemediationAdvisor` default impl + recommendation surfaces
      (per-cell sheet + scan-level banner stack)
- [ ] `HistoryView`: past scans via SwiftData (handles "(images cleared)" state)
- [ ] `SettingsView`: validator regex, default layout, provenance toggle,
      retention, storage cap, gap threshold, outlier sigma
- [ ] `OnboardingView`: 2–3 screens, skippable
- [ ] All `ScanError` states have user-facing messages

## Phase 6 — Validation & Release (Day 3)
- [ ] Seed `TestImages/46__sparsed_missing/` bundle (manual ground truth
      generated by dogfooding the v1 pipeline)
- [ ] Testbed pass rate: ≥ 95% image-level decode-count match,
      ≥ 99% per-cell decode reliability across the corpus
- [ ] Performance test: 100-code end-to-end < 3s on iPhone 12
- [ ] Snapshot tests for `ImageAnnotator` (≤ 1% pixel tolerance)
- [ ] Integration test: `ScanPipelineIntegrationTests` against the seed bundle
- [ ] Xcode Cloud workflows: PR validation + nightly testbed + release upload
- [ ] TestFlight build
- [ ] Physical device testing (iPhone, not just simulator)
- [ ] App Store Connect metadata + screenshots (CEL-branded, lab-use copy)
- [ ] Privacy declarations: camera, photo library, Files (no network use)
- [ ] Submit for review
